PROJECT OVERVIEW

從草圖到三維模型

這項作品的目標是設計一張兼具現代感與實用性的咖啡桌，透過獨特的桌面分割、簡潔線條與平衡比例，呈現適合現代生活空間的家具造型。

DESIGN PROCESS

  1. 草圖與輪廓 — 使用 Sketch 工具建立桌面的基本形狀。
  2. 建立立體結構 — 使用 Extrude 將 2D 草圖轉為 3D 實體。
  3. 調整尺寸與邊角 — 修正高度、寬度與支撐厚度，並以 Fillet 圓滑邊緣。
  4. 組裝與材質 — 組合桌面與底座，加入木紋與色彩，檢查比例並完成展示模型。

DESIGN CONSIDERATIONS

作品文件亦探討耐用性、材料運用與減少製作浪費的方向。文件中提出柚木或回收木材、水性塗裝及便於組裝的結構作為可持續設計考量；這些是設計方向，而非已驗證的材料測試結果。
